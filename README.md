# bhamm-midlife-apoe-study
 
<b>Project Title:</b> APOE ε4 and plasma Aβ42/40 levels are associated with differences in episodic memory and related brain activation in middle-aged women 
<b>Authors:</b> Rikki Lissaman, Sricharana Rajagopal, Andrea L. Benedet, Ilaria Pola, Kübra Tan, Burak Arslan, Henrik Zetterberg, Gillian Einstein, Pedro Rosa-Neto, & M. Natasha Rajah.

Script descriptions:
* script-1_clean-data.Rmd = R Markdown script that imports the BHAMM Study master database, filters out participants according to the study inclusion/exclusion criteria, then outputs the data for later analyses.
* script-2_analyze-demo-biomarker-cvlt.Rmd = R Markdown script that imports cleaned data generated by script-1_clean-data.Rmd and then examines APOE e4-related differences in: (1) demographics, (2) plasma AD biomarkers, (3) the California Verbal Learning Test (CVLT). It then outputs data to be used in trial-level analysis.
* script-3_analyze-task-data.Rmd = R Markdown script that imports trial-level behavioral (task) data, merges this with demographic and biomarker data generated by script-2_analyze-demo-biomarker-cvlt.Rmd, conducts key analyses and exports figures.
